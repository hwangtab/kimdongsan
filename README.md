# 김동산과 블루이웃 — EPK

정규 1집 《김동산과 블루이웃》(2026.11.17, 애프터눈) 발매와 12.04 쇼케이스를 위한
국문·영문 EPK 사이트입니다.

- 프레임워크: Next.js 16 (App Router, Turbopack) · React 19 · TypeScript
- 스타일: Tailwind CSS 4 (`@theme` 토큰은 `app/globals.css`)
- 분위기: 1990년대 PC통신(VGA 남색) · 도스 창 크롬 · 픽셀 도스 폰트
- 배포: Vercel (환경변수 없음)

## 실행

```bash
npm install
npm run dev      # http://localhost:3000 → /ko
npm run build
npm run lint
```

## 자산

원본은 `media-src/`에 있고 저장소에는 포함하지 않습니다.

```bash
npm run assets:audio      # 60초 발췌 → public/audio/preview/*.m4a
npm run assets:waveforms  # 파형 → data/waveforms.json
npm run assets:images     # 커버·포스터·라이브·멤버 → public/images
npm run assets:og         # 1200×630 소셜 카드 7장 (페이지별, 사이트와 같은 폰트 서브셋 사용)
npm run assets:favicon    # app/favicon.ico (16·32·48px, 16px는 전용 그리드)
```

발췌 시작점은 `scripts/prepare-audio.sh`의 `STARTS` 배열에서 바꿉니다.
현재 값은 에너지 스캔으로 고른 후보이므로, 김동산 쪽에서 한 번 들어보고
마디를 지정해 주는 것이 좋습니다.

## 사실 표기 원칙

- 앨범은 **2026.11.17 발매 완료**. "발매 예정"으로 쓰지 않습니다.
- 2017 한국대중음악상 선정위원회 특별상은 《젠트리피케이션》 참여 음악인 **공동 수상**입니다.
- 〈시간〉은 김동산의 아버지가 아니라 **석관시장 시계방의 시계 수리공(1930년생)** 이야기입니다. (오마이스타 2018.10.29)
- 출장작곡 소요 시간은 **10~30분 인터뷰, 20분~두 시간 작업**으로 적습니다. 자료마다 다릅니다.
- 롱플레이어는 **2017년 5월** 문을 연 되살림 가게 겸 LP바입니다.
- 2019 한국대중음악상은 최우수 포크 음반 **후보**입니다.
- "한국의 우디 거스리"는 별명으로만 씁니다.
- 밴드 7년째·첫 정규는 류준철의 공개 글(2026.11.15)에 근거합니다. **7년은 밴드가 함께한 시간**이고, 김동산은 출장작곡(2010년) 이전부터 오래 음악을 해왔습니다.
- 12.04 얼리버드 20,000원은 **매진**, 사전예매 30,000원·할인권 20,000원은 판매 중입니다.
- 예매 CTA는 스튜디오 놀 공연 페이지(`#book`)로 보냅니다.
- 〈돈으로 살 수 없는 것〉은 **2018년 2월** 서촌(체부동) ‘궁중족발’에서 만든 곡입니다. 2016년 새 건물주가 보증금 3,000만→1억 원·월세 297만→1,200만 원을 요구했고, 2017.10–2018.06 강제집행이 12차례 있었으며, 2017.11.09 2차 집행에서 김우식의 왼손 손가락 네 개가 부분 절단됐습니다. **건물주는 인상 요구를 부인**했으므로 ‘부부에 따르면’으로 적습니다.
- 같은 사건의 결말(2018.06 망치 사건·2018.08 철거·상가임대차보호법 개정)은 곡이 다루는 범위 밖이므로 공개 문안에는 넣지 않습니다.
- 〈4인 가족〉은 **2016.05**에 만든 우장창창 서윤수 사장의 노래이고, 강제퇴거는 그 뒤인 **2016.07.18**입니다. 곡은 퇴거 전에 만들어졌습니다.
- 〈골든타임〉은 무악동 옥바라지 골목 **구본장 여관 이길자** 사장의 노래입니다. 2016.05.17 강제퇴거. 박완서 《그 많던 싱아는 누가 다 먹었을까》의 배경이 된 골목입니다.
- 〈수원 지동 29길〉이 정확한 제목입니다(〈지동 29길〉 아님). 2016년 《젠트리피케이션》 수록. 화성 유네스코 등재 뒤 재개발로 밀려난 지동의 야채 장수 할머니 이야기이며, ‘열세 평 반 보상금’과 ‘30년 전 잃어버린 자동차세’는 가사에 나오는 사실입니다.
- 〈되돌아보는 노래〉는 **2007년 삼성 비자금 의혹을 폭로한 김용철 변호사**의 사연으로 만든 곡입니다. 공개 문안에는 ‘삼성 X파일’이라는 표현을 쓰지 않습니다(불법 도청이 논점이 되므로).
- 멤버 소개는 확인된 이력만 적습니다. 류준철은 재즈 피아니스트로 앨범 세 장(《My Favorite Things》 2019, 《From My Childhood 'til Now》 2020, 《Landscape》 2022), 이인우는 수원 재즈씬 베이시스트, 김예준은 록 밴드 활동을 거쳐 온 드러머입니다. **김예준의 버즈 이력은 사이트에 쓰지 않습니다** — 밴드 정체성이 버즈 쪽으로 읽히기 때문입니다.
- 롱플레이어는 **13:00–22:00, 월·화 휴무**입니다(수원문화재단·수원문화지도 기준). 2층은 100석 규모 공연장으로 등록된 공연시설입니다. 블로그마다 시간이 달라 공식 채널 기준을 씁니다.
- 강정피스앤뮤직캠프 컴필레이션 《이름을 모르는 먼 곳의 그대에게》는 **2024.10 CD 선발매(완판) → 2025.02.07 음원 발매**입니다(12팀·13트랙).
- 테이크아웃드로잉 컴필레이션은 **2016.02.18** 발매이고, 수록곡 제목은 〈**Game, Invisible Enemy**〉입니다(〈Invisible Enemy〉 아님).
- 〈물결〉 2024 싱글의 코러스는 **세민**, 2026 앨범 버전은 **강가 히말라야**입니다. 두 사람을 구분해 적습니다.
- 경양식집 비유는 밴드의 태도·방식에만 씁니다. 곡의 주제(해고·재개발·전쟁·상여소리)에는 쓰지 않습니다.

## 폰트

1990년대 PC통신/도스 화면을 기준으로 짠 2.5단 체계입니다. 도스 계열 세 폰트는 모두
단일 무게(400)라서 굵기 대신 **크기·색·반전**으로 위계를 만듭니다.

| 층 | 폰트 | 쓰는 곳 | 라이선스 / 처리 |
| --- | --- | --- | --- |
| UI · 제목 | **도스고딕** (leedheo) | 내비, 라벨, 제목, 숫자, 버튼, 트랙리스트 | MIT. 16KB 서브셋을 저장소에 커밋 |
| 읽기 | **도스명조** (leedheo) | 긴 바이오, 곡 노트, 크레딧, 가사, 인용 | MIT. 20KB 서브셋을 커밋 |
| 기호 | **미래로글꼴** (leedheo) | `· — 《》 → ★ ─│┌` 등 도스고딕에 없는 문자 | MIT. 2KB 기호 전용 서브셋 |
| 인쇄 전용 | Pretendard | 인쇄용 원시트만 | OFL. 원시트 페이지에서만 로드 |

도스고딕과 도스명조는 같은 제작자의 같은 1024upem 격자라 섞어 써도 베이스라인이
어긋나지 않습니다. 도스고딕은 **문장부호·박스문자가 하나도 없어서**, 같은 계열의
미래로글꼴을 폰트 스택 두 번째에 두고 글자 단위로 폴백합니다.

```bash
npm run assets:dos-font  # 도스고딕·도스명조·기호 서브셋 (총 38KB)
npm run assets:font      # 인쇄용 Pretendard 서브셋 (원시트 전용)
npm run assets:og        # OG 카드 7장 (도스 폰트로 렌더, 페이지별)
```

원본 TTF는 `media-src/fonts/`에만 두고, MIT 라이선스라 서브셋 결과물은 커밋합니다.
출처는 <https://github.com/hurss/fonts>. 폰트 저작권 고지는 `NOTICE.md`에 있습니다.

### 타입 스케일

도스 폰트는 1em = 16px 격자라서 **16의 배수에서만 획이 1px로 떨어집니다.**
16 / 32 / 48 / 64px 네 단만 쓰고, 작은 라벨도 16px 아래로 내리지 않습니다.
`body` 16px · `.longform` 16/30px · 제목은 모바일 32/48, 데스크톱 48/64입니다.

### 인쇄

`@media print`에서 토큰(`--void`·`--ink`·`--signal`·`--ticket` …)을 종이용
흑백 팔레트로 뒤집습니다. 유틸리티 클래스마다 덮어쓰지 않아도 모든 강조색이
자동으로 인쇄 대비를 확보합니다. 원시트는 Pretendard로 따로 고정됩니다.
